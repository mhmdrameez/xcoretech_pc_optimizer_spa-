What it cleans

What it removes, and what it never touches.

On Windows it cleans five places. That's the whole list.

✓Cleans when you press Clean up

  • Your Temp folder %TEMP%
  • The Windows Temp folder C:\Windows\Temp
  • Prefetch files Windows rebuilds them
  • Google Chrome's cache Default profile
  • Microsoft Edge's cache Default profile

–Never touches

  • Your documents, photos, music and videos
  • Browser history, passwords and cookies. Only the cache folder is cleared.
  • System32, WinSxS and Program Files blocked in the code
  • /System, /usr, /etc and other system folders on macOS and Linux blocked too
  • Installed programs and their settings

On macOS it clears the Chrome, Edge and Brave caches in ~/Library/Caches and old crash reports in ~/Library/Logs/DiagnosticReports. On Linux it clears the thumbnail cache and the Chrome, Chromium, Edge and Brave caches in ~/.cache.

How it works

Scan. Check. Clean up.

  1. Scan

    It walks through those five folders and counts what's there. You watch the number of files and the space they take go up as it finds them.

  2. Check

    Open "See which files will be removed" and you get the full list, path by path. When you press Clean up, it asks you to confirm first.

  3. Clean up

    It deletes only what the scan found. Files Windows is still using are skipped and left alone. The "So far" card keeps your running total.

Apps that start when you sign in

Most slow starts aren't your system's fault.

It's the apps that all decided they need to open the moment you sign in. XCoreTech lists every one of them, with the exact command it runs and whether it's set for just you or for everyone on the computer.

Flip a switch to stop one from opening. Nothing gets uninstalled, and you can flip it back any time. It reads the registry and Startup folder on Windows, LaunchAgents on macOS, and autostart entries on Linux.

Apps that start with Windows

Turning an app off here only stops it from opening at sign-in. Nothing is uninstalled.

Developer caches

Written any code lately? Check this.

npm, pnpm, pip, uv, conda and Playwright quietly keep gigabytes of downloads you'll never look at again. XCoreTech measures each one and clears the ones you tick.

Your tools download anything they need again, so nothing breaks. It only removes pnpm packages and uv entries that nothing on your PC uses.

Large files

Finds the biggest files on any drive, from 50 MB up to 5 GB and beyond. Move them to the Recycle Bin (the Trash on macOS and Linux), or delete them for good. System and program folders are left out.

Quick fixes

On Windows: an internet fix (DNS, Winsock and IP reset), a memory clean-up, and a Windows Update and printer fix. On macOS and Linux, the internet fix flushes the DNS cache.

Cleans when you sign in

XCoreTech starts when you sign in, does a quick clean in the background, then waits in the system tray or menu bar until you need it.

Updates itself

On Windows and with the Linux AppImage, new versions download quietly and you choose when to restart. On macOS, run the install command again to update.

Open source

Free and open source. Come build it with us.

XCoreTech is open source under the GNU GPL-3.0 license. Every line is on GitHub, so you can read exactly what it does before you run it. With anything that deletes files, you should. Start with platform.js for the folders it cleans and cleaner.js for how it deletes.

  • Found a bug? Open an issue with your system and what happened.
  • Have an idea? More browsers to clean, more developer caches, translations. Suggest it in an issue.
  • Want to code? Pull requests are welcome. Testing on a Linux distro or Mac we haven't tried helps a lot too.

    I built XCoreTech while working as a hardware engineer. A lot of the systems I saw weren't broken. They were slow because they had never been cleaned properly: temp folders full, caches piling up, too many apps starting with Windows.

    Questions
    
      
    Things people usually ask.
    
      
    
        
    
          Is it really free?
          
    Yes. It's free and open source under the GPL-3.0 license: no activation, no trial timer, no payment screen.
    
        
    
        
    
          Is it open source? Can I contribute?
          
    Yes. The full source code is on GitHub under the GNU GPL-3.0 license. Anyone can read it, report bugs, suggest features and send pull requests.
    
        
    
        
    
          Which systems does it run on?
          
    Windows 10 and 11 (32- and 64-bit), macOS on Apple Silicon and Intel, and 64-bit Linux as an AppImage, .deb or .rpm. On macOS and Linux it installs with one command; see Download.
    
        
    
        
    
          Can it delete something I need?
          
    It only looks in a handful of temp and cache folders (the full list is above), and system folders are blocked in the code. It asks before deleting anything. The worst you'll notice is a browser loading some sites a little slower the first time while its cache fills up again.
    
        
    
        
    
          Windows or macOS warned me about the app. Is that normal?
          
    Yes. It isn't code-signed yet, so your system doesn't recognise it. On Windows, click "More info", then "Run anyway". On macOS, right-click the app and choose Open, or on macOS 15 and later use "Open Anyway" in System Settings → Privacy & Security. The install command avoids the macOS prompt. If you'd rather check first, the full source is on GitHub.
    
        
    
        
    
          Does it run in the background?
          
    Yes. It starts when you sign in, does a quick clean, and waits in the system tray (the menu bar on macOS). Closing the window hides it there. To quit completely, click the tray icon and choose Exit.
    
        
    
        
    
          Does it send any of my data anywhere?
          
    Your files, file names and browsing history never leave your PC. When the app opens, scans and cleans, it sends a small usage log to our server: your computer's name, system version, processor, total and free memory, roughly where you are (city and country, looked up from your IP address), how much was cleaned, and error details if something crashes. It doesn't ask for your name, email or phone number. The live numbers on this page are counted from that log.
    
        
    
        
    
          How do I uninstall it?
          
    Windows: Settings → Apps → Installed apps → XCoreTech PC Optimizer → Uninstall (its settings and history go too). macOS: drag it from Applications to the Trash. Linux: sudo apt remove xcoretech-disk-cleaner or sudo dnf remove xcoretech-disk-cleaner, or just delete the AppImage.
