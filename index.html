What it cleans

What it removes, and what it never touches.

A cleaner is only useful if you can trust it. So here's the whole deal, in plain words.

✓Cleans, when you tick it

  • Windows & app temp files %TEMP%
  • Windows Update downloads that already installed SoftwareDistribution
  • Browser caches Chrome, Edge, Firefox
  • Thumbnail and icon caches rebuilt automatically
  • Crash dumps and old error reports WER

–Leaves alone, always

  • Documents, photos, music and videos
  • Saved passwords and browser sign-ins
  • Installed programs and their settings
  • Anything in the list you didn't tick

How it works

Three clicks. No surprises.

  1. Scan

    It looks through the usual places junk piles up and adds up what's there. Takes about as long as making a cup of tea, usually less.

  2. Review

    You get a plain list with sizes and folder paths. Untick anything you want to keep. Nothing has been deleted yet.

  3. Clean

    Only what you selected is removed. The History tab keeps a record of every run, so you always know what happened.

    Questions

    Things people usually ask.

    Is it really free?

    Yes. Download it, use it, keep it. No trial timer, no "upgrade to clean the rest" pop-up halfway through a scan.

    Can it delete something I need?

    It only cleans locations that hold temporary or rebuildable data, and only the items you leave ticked. Your personal files aren't on the list. If you're unsure about a category, untick it.

    Windows showed a SmartScreen warning. Is that normal?

    It's common for newer apps from smaller developers. Click "More info", then "Run anyway". If you'd rather check first, the full source is on GitHub.

    Does it send any of my data anywhere?

    No personal files, browsing history or file names are collected. The app may check GitHub for updates, and that's it.

    How do I uninstall it?

    Like any other app: Settings → Apps → Installed apps → XCoreTech → Uninstall.
